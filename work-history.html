업무 이력

모델과 운영을 함께 다뤄온 과정

UMS 사람 행동 인식 시스템의 유지보수와 AI 모델 개발을 담당했습니다. 현장 데이터로 모델을 보완하고, 추론 시스템을 개선하며, 실험과 실증 결과를 기술 문서로 연결했습니다.

2025.10~12

01 객체 추적과 행동 인식 조사

입사 후 객체 추적과 GCN 기반 행동 인식 모델을 조사했습니다. UMS 사람 행동 인식 시스템의 유지보수와 AI 모델 개발을 주요 업무로 맡았습니다.

2026.01~04

02 현장 오류를 학습과 개선으로 연결

야간·조명 전환·배경 물체에서 발생한 오탐을 수집해 YOLO 재학습과 모델 변환·운영 검증을 진행했습니다. EfficientNet 사람 확인 모델에는 저화질 사람과 사람처럼 보이는 물체의 데이터를 보강하고, 오탐과 사람 누락을 함께 살폈습니다.

카메라의 프레임 미수신과 재연결 문제가 다른 영상 분석에 영향을 주는 경로를 진단하고 개선안을 시험했습니다. GCN 기반 행동 인식을 연구하며 다인 관절 데이터와 시간 구간에 따른 입력을 비교하고, 실증 준비를 위해 협력기관 모델의 입력 좌표계와 실행 환경을 맞췄습니다.

2026.05~06

03 현장 실증과 시스템 통합 준비

모델 입력과 전처리, 이벤트 후처리를 점검하고 현장 실증과 운영 개선을 진행했습니다. 기존 분석기를 모듈화하고 이벤트 서비스 분리를 실험하며, 데이터 전달 방식에 따른 비용을 비교했습니다.

기존 팀의 DeepStream 모듈에 로컬 모델과 이벤트 처리 경로를 이식하는 작업을 준비·진행했습니다.

2026.07~08

04 다채널 추론과 이벤트 흐름 개선

DeepStream에 모델을 이식하고 단일 PGIE 구성으로 전환하면서 다채널 처리 성능과 자원 사용량을 계측했습니다. 이벤트 영상의 저장 경로를 개선하고, 입력부터 이벤트 저장까지 이어지는 동작을 확인했습니다.

VLM 추론 엔진의 API 호환성과 자원 사용을 비교하고 이벤트 검색 기능을 연동했습니다. 다채널 운영 조건을 검토하면서 과제 보고서에 필요한 테스트 결과와 학습 데이터 출처도 정리했습니다.

2026.09~10

05 모델 비교와 검증 범위 확장

MoViNet 기반 폭행 후보 처리 경로를 구성하고 GPU 전처리와 부하 시험을 진행했습니다. 현장 오탐을 반영한 모델 학습과 웹 관제 개선도 함께 수행했습니다.

VideoChat과 Qwen을 같은 입력 조건에서 비교하고 운영 경로와 연결했습니다. 비식별화 모델을 재학습·평가하고 실패 영상의 검수 자료를 정리했으며, RAVLM 후보는 운영과 분리한 환경에서 실험했습니다. 자동 점검과 결과 보고 절차도 구성했습니다.

연구개발 문서와 협업

06 구현과 실증을 문서로 설명

모델과 시스템을 개발하면서 패스트트랙·SBA 과제의 연구개발계획서, 중간·최종보고서, 실증·회의·발표 자료를 함께 작성했습니다. 기술 개발 내용과 평가 지표를 연결하고, 실험 조건과 결과를 근거로 정리했습니다.

  • 상반기에는 중간보고서를 취합·검토하고, 현장 실증 데이터 보고서와 계획서 수정안을 작성했습니다.
  • 하반기에는 최종보고서 작성과 성능지표 테스트 자료 준비를 진행하고, 테스트 결과와 학습 데이터 출처를 정리해 전달했습니다.
  • 시험 피드백과 정기회의에 대응하며 운영 문제, 개선 내용, 후속 검증 과제를 문서로 공유했습니다.
개발한 내용을 다른 사람이 판단하고 이어갈 수 있도록 정리했습니다.

실험과 실증의 조건, 완료한 작업과 남은 문제를 구분해 설명했습니다. 모델 개선과 운영 경험을 연구개발 문서에 연결하며 협업에 필요한 근거를 전달했습니다.
