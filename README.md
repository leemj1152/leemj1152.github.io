# 이명재 · 영상 AI 개발과 검증

[포트폴리오](https://leemj1152.github.io/) · [이력서](https://leemj1152.github.io/resume.html)

UMS 사람 행동 인식 시스템의 모델 개발·평가, DeepStream 통합, VLM 오류 분석, 비식별화 후보 학습과 연구개발 경험을 소개합니다.

[기간별 업무 기록](https://leemj1152.github.io/work-history.html)에서 담당 업무의 흐름을 확인하실 수 있습니다.

## 구성

- `index.html`: 소개, 대표 프로젝트, UMS 처리 흐름, 경력과 연구 관심
- `work-history.html`: 기간별 업무 기록과 연구개발 문서 경험
- `projects/`: DeepStream, VLM, 비식별화 프로젝트 상세
- `resume.html`: 인쇄 가능한 이력서
- `assets/`: 공통 스타일, 인터랙션, 이력서 PDF와 공유 이미지

HTML, CSS, JavaScript로 구성한 정적 사이트입니다. GitHub Pages의 `main` 브랜치 루트에서 배포합니다.
