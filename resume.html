현장의 오류를 데이터와 시스템 개선으로 연결하는 영상 AI 연구원입니다. 사람 행동 인식 시스템을 유지보수하며 모델 학습·평가, 실시간 추론 통합과 운영 검증을 수행했습니다. 실험 결과와 실증 경험을 연구개발계획서·최종보고서로 정리했습니다.

경력

AI연구소 연구원 2025.10–현재

UMS 사람 행동 인식 시스템 · 연구개발 과제

  • 현장 오탐·미탐 데이터를 분석하고 검출·분류 모델을 재학습·평가했습니다.
  • 행동 인식 모델과 VLM 재확인 경로를 비교·연동하고 운영 오류를 개선했습니다.
  • 기존 팀 모듈을 기반으로 DeepStream에 모델을 이식하고 이벤트·영상·DB 연결을 점검했습니다.

대표 프로젝트

01

VLM 사람 확인 모델 비교와 오류 분석

동일한 입력과 샘플링 조건에서 VideoChat·Qwen의 사람 확인 결과를 비교했습니다. 비사람 오통과 감소와 새롭게 발생한 사람 미탐을 함께 분석해 모델 선택과 후속 검증에 반영했습니다.

입력 처리와 응답 형식을 점검하고, 기존 API와의 운영 연계 및 복구 절차를 정리했습니다.

Python · VLM · 비교 평가 · API 연동
02

DeepStream 통합과 처리 경로 개선

기존 팀 모듈에 로컬 모델과 이벤트 경로를 이식하고, 단일 PGIE 구성과 GPU 전처리를 적용했습니다. 운영 비교에서 추론 속도를 유지하면서 GPU와 메모리 사용량이 줄어드는 것을 확인했습니다.

다채널 부하시험에서는 실제 영상 수신, 검출 속도, VLM 지연과 이벤트 미디어 저장을 함께 점검했습니다.

DeepStream · TensorRT · ONNX · Docker · RTSP
03

현장 데이터 기반 모델 학습과 검증

배경 물체와 사람 유사 물체의 오탐을 수집해 YOLO·EfficientNet 학습 데이터를 보강했습니다. 학습 이후 시간대의 오탐 표본과 기존 사람 표본을 비교하고, 원거리·가림 장면의 누락을 추적했습니다.

행동 인식·비식별화 후보도 입력 구성과 클래스별 오류를 분석하고 후속 검수 자료를 정리했습니다.

PyTorch · OpenCV · YOLO · EfficientNet · 데이터 검수
